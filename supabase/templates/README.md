# อีเมลยืนยันการสมัครบัญชี

ไฟล์ `confirm-signup.html` เป็นเทมเพลตภาษาไทย ใช้สีและชื่อแบรนด์ตามเว็บตู้เซฟ โดยใช้ตารางและ inline CSS เพื่อรองรับโปรแกรมอ่านอีเมล และไม่โหลดรูปหรือฟอนต์จากภายนอก

## นำไปใช้ใน Supabase

1. เปิดโปรเจกต์ที่ต้องการใน Supabase Dashboard แล้วไปที่ Authentication → Email Templates (บางหน้าจอแสดงอยู่ใน Emails → Templates)
2. เลือก **Confirm sign up**
3. ตั้งหัวข้ออีเมล (Subject) เป็น **ยืนยันอีเมลของคุณ — ตู้เซฟ**
4. เก็บสำเนาหัวข้อและเนื้อหาเทมเพลตเดิมไว้ก่อน แล้วคัดลอกเนื้อหาทั้งไฟล์ `confirm-signup.html` ไปใส่ในส่วน Body/Source
5. ตรวจตัวอย่างก่อนบันทึก การบันทึกใน Dashboard จะเปลี่ยนอีเมลยืนยันที่ส่งครั้งถัดไปของโปรเจกต์นั้น
6. ทดสอบสมัครด้วยบัญชีทดสอบ ตรวจอีเมลทั้งบนมือถือและคอมพิวเตอร์ แล้วกดปุ่มยืนยันเพื่อตรวจว่ากลับเข้าเว็บที่ถูกต้องและเข้าสู่ระบบได้

คง `{{ .ConfirmationURL }}` ทั้งในปุ่มและลิงก์สำรองไว้ตามเดิม Supabase จะแทนค่าด้วยลิงก์ยืนยันเฉพาะครั้ง อย่าเปลี่ยนเป็น URL หน้าเว็บโดยตรง และอย่าใส่ลิงก์ยืนยันของผู้ใช้จริงลงในไฟล์นี้

การเพิ่มไฟล์นี้ใน repository หรือ build/deploy เว็บ **ยังไม่เปลี่ยนอีเมลที่ส่งจริง** ต้องนำไปตั้งค่าใน Supabase ตามขั้นตอนด้านบนก่อน ไม่มีการเปลี่ยนชื่อ/ที่อยู่อีเมลผู้ส่งหรือ SMTP ในงานนี้

## ตรวจสอบก่อนใช้งานจริง

- ตรวจ Site URL และ Redirect URLs ของโปรเจกต์ให้ตรงกับเว็บที่ใช้งาน
- ตรวจชื่อผู้ส่ง ที่อยู่อีเมลผู้ส่ง และการส่งถึงกล่องจดหมายด้วยบัญชีทดสอบ
- ตรวจปุ่มและลิงก์สำรอง รวมถึงการแสดงผลใน Gmail/Outlook ที่ต้องการรองรับ
- หากต้องย้อนกลับ ให้คืนหัวข้อและเนื้อหาจากสำเนาเทมเพลตเดิมใน Dashboard
